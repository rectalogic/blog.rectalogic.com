Side projects I've been working on over the past couple of years in somewhat reverse chronological order.

2024/04-present [Asbury Park happy hours](https://github.com/rectalogic/asburypark)
: Static website listing happy hours in Asbury Park, NJ.  Used to be jekyll, rewrote in Rust using [minininja](https://docs.rs/minijinja/latest/minijinja/).  The "database" is a [RON](https://docs.rs/ron/latest/ron/) file.

2026/02 [ntsc](https://github.com/rectalogic/ntsc)
: [frei0r](https://dyne.org/software/frei0r/) video filter plugin that uses [ntsc.rs](https://ntsc.rs) to emulate analog TV and VHS artifacts. 

2026/01-2026/02 [cyd-video](https://github.com/rectalogic/cyd-video)
: Rust no_std video player for the CYD ("Cheap Yellow Display) ESP32-2432S028R microcontroller. It works but the performance is not good enough. It's based on MJPEG using the tjpgdec-rs decoder (see below) and riffparse (see below).

2026/01-2026/02 [riffparse](https://github.com/rectalogic/riffparse)
: Rust no_std RIFF/AVI video format demuxer. Extracts audio amd video frames from an AVI file.

2025/05-2026/02 [frei0r-rs2](https://github.com/rectalogic/frei0r-rs)
: Fork of the Rust frei0r-rs framework for building frei0r video plugins in Rust. Made major changes to the API.

2026/02 [tjpgdec-rs](https://github.com/rectalogic/tjpgdec-rs)
: Some vibe-coded performance improvements to the tjpgdec-rs JPEG decoder used with cyd-video.

2026/02 [esp32-tv](https://github.com/rectalogic/esp32-tv)
: ESP32 video player fork with vibe coded fixes and support for IR receiver.

2026/01 [esp32-202432S028_video_player](https://github.com/rectalogic/esp32-202432S028_video_player)
: ESP32 video player fork, ported to [platformio](https://platformio.org).

2026/01 [cyd-bevy-life](https://github.com/rectalogic/cyd-bevy-life)
: Conway's game of life on no_std ESP32 MCU using the Rust [Bevy](https://bevy.org) game engine.

2025/12 [webvfx-rs](https://github.com/rectalogic/webvfx-rs)
: Rust frei0r video plugin using the [Blitz](https://blitz.is) web engine. It takes input video frames and injects them into HTML images in a web page, then renders the result as the output.

2025/04-2025/12 [mediafx-frameserver](https://github.com/rectalogic/mediafx-frameserver)
: "Out of process" frei0r video plugins. This is a Rust framework with Python and Typescript APIs so that video plugins can be written as standalone Python, Typescript or Rust applications. The plugin communicates with the subprocess via stdio, and sends/receives frames of video via shared memory.

2025/12 [Caption](https://github.com/rectalogic/Caption)
: Vibe coded SwiftUI iOS application for live audio transcription using NVIDIA Parakeet via the [FluidAudio](https://github.com/FluidInference/FluidAudio) SDK.

2025/11 [rapidfire](https://github.com/rectalogic/rapidfire)
: Simple Rust Bevy/[Avian3d](https://crates.io/crates/avian3d) "game" where you walk around a generated cityscape and shoot tons of blocks.

2025/11 [nannou](https://github.com/nannou-org/nannou/pull/1031)
: PR to upgrade nannou to Bevy 0.17

2025/07-2025/11 [bevy_web_video](https://github.com/rectalogic/bevy_web_video)
: Support for streaming video into Rust Bevy textures on the web platform (webgpu/webgl2). See the [demo](https://rectalogic.com/bevy_web_video/)

2025/10 [sbx](https://github.com/rectalogic/sbx)
: Unfinished attempt at a sandboxing CLI in Rust using the native macOS sandbox primitives ("seatbelt") and a local HTTP proxy for network filtering.

2025/10 [tumbler](https://github.com/rectalogic/tumbler)
: Mobile web based Rust Bevy 3D dice simulation. Runs in the browser and uses the devicemotion accelerometer to manipulate the dice. [Demo](https://rectalogic.com/tumbler/)

2025/10 [blendiff](https://github.com/rectalogic/blendiff)
: Rust tool to dump binary [Blender](https://www.blender.org) project files as diffable text.

2025/08-2025/10 [bevy_av1](https://github.com/rectalogic/bevy_av1)
: [AV1](https://aomedia.org/av1-features/) video decoder for the Bevy game engine. Based on [dav1d](https://crates.io/crates/dav1d) which are Rust bindings for libdav1d - but plan to switch to [rav1d](https://crates.io/crates/rav1d) which is a pure Rust port of dav1d.

2025/09 [bevy_p2p](https://github.com/rectalogic/bevy_p2p)
: Incomplete peer-to-peer Rust experiments in Bevy, using [nostr](https://nostr.com) and [iroh](https://www.iroh.computer).

2025/07-2025/09 [bevy_blitz](https://github.com/rectalogic/bevy_blitz)
: Render web pages to Bevy textures using the Rust [Blitz](https://blitz.is/) HTML/CSS rendering engine.

2025/08 [bevy_luminance_material](https://github.com/rectalogic/bevy_luminance_material)
: Attempt at an effect implemented as a Rust Bevy material that converts a texture into a luminance texture in a prepass, then be used as `StandardMaterial::depth_map`. The effect is not that good.

2025/07-2025/08 [bevy_arcball_camera](https://github.com/rectalogic/bevy_arcball_camera)
: Rust [Arcball](https://graphicsinterface.org/wp-content/uploads/gi1992-18.pdf) camera controller for [Bevy](https://bevy.org). Supports mouse and touch controls.

2025/06-2025/07 [l0ttie](https://github.com/rectalogic/l0ttie)
: A Rust [frei0r](https://dyne.org/software/frei0r/) video source plugin that renders  [Lottie](https://lottie.github.io) animation files.

2025/06 [diff-video-action](https://github.com/rectalogic/diff-video-action)
: A [GitHub action](https://docs.github.com/en/actions/get-started/understand-github-actions) that compares a set of videos to reference videos, and generates audio/visual diff videos if any fail to compare visually/audibly identical.

2023/10-2026/01 [renderwindow](https://github.com/rectalogic/renderwindow)
: A C++ [Qt QML](https://doc.qt.io/qt-6/qtqml-index.html) QQuickWindow subclass that supports offscreen rendering of its contents via [QQuickRenderControl](https://doc.qt.io/qt-6/qquickrendercontrol.html)

2025/05 [llm-tools-mcp](https://github.com/rectalogic/llm-tools-mcp)
: [MCP](https://modelcontextprotocol.io) tools support for the [llm](https://llm.datasette.io/en/stable/usage.html) command line tool.

2025/04 [skysearch](https://github.com/rectalogic/skysearch)
: Typescript tool to subscribe to the [BlueSky Jetstream](https://docs.bsky.app/blog/jetstream), compute an [embedding](https://huggingface.co/spaces/hesamation/primer-llm-embedding) for every post using [MediaPipe Text Embedder](https://ai.google.dev/edge/mediapipe/solutions/text/text_embedder/web_js), and compare cosine similarity to a query. Display any posts that are semantically similar enough to the query.

2025/03-2025/04 [breakin](https://github.com/rectalogic/breakin)
: Classic BreakOut game but in 3D using Rust Bevy game engine - BreakIn to the cube.

2025/03-2025/04 [toolchat](https://github.com/rectalogic/toolchat)
: Python tool to multimodal chat with LLMs, supports [MCP servers](https://modelcontextprotocol.io/).

2024/08-2025/04 [mediafx-py](https://github.com/rectalogic/mediafx-py)
: Unfinished Python experiments in audio/video editing with visual effects. Based on [pyav](https://pyav.org/) and eventually [pygfx](https://pygfx.com/)

2024/11-2025/04 [langchain-mcp](https://github.com/rectalogic/langchain-mcp)
: [MCP](https://modelcontextprotocol.io/) tool support for [LangChain](https://www.langchain.com). Obsoleted by [langchain-mcp-adapters](https://github.com/langchain-ai/langchain-mcp-adapters).

2025/03 [blender-mcp](https://github.com/rectalogic/blender-mcp)
: [MCP server](https://modelcontextprotocol.io/quickstart/server) that can run Python code in [Blender](https://www.blender.org).

2025/03 [pydantic-mcp](https://github.com/rectalogic/pydantic-mcp)
: [MCP](https://modelcontextprotocol.io) tool calling support for [Pydantic AI](https://ai.pydantic.dev/). Obsoleted by [native MCP](https://ai.pydantic.dev/mcp/) support.

2025/02-2025/03 [skybedding](https://github.com/rectalogic/skybedding)
: Rust realtime BlueSky post [jetstream](https://docs.bsky.app/blog/jetstream) feed, filtered on a query using embeddings similarity via a local LLM.

2025/01-2025/02 [terp](https://github.com/rectalogic/terp)
: Rust Bevy based drawing interpolation animation editor. Inspired by [LizardLadder](http://www.tedwiggin.com/LizardLadder/).

2024/12-2025/01 [clay-rs](https://github.com/rectalogic/clay-rs)
: Rust bindings for [Clay](https://github.com/nicbarker/clay). Includes a renderer built with [macroquad](https://crates.io/crates/macroquad).

2024/12 [skyreaper](https://github.com/rectalogic/skyreaper)
: Simple unfinished Rust Bevy game using [avian3d](https://docs.rs/avian3d/latest/avian3d/).

2024/10 [flux3d](https://github.com/rectalogic/flux3d)
: Javascript text to image to 3D model using [FLUX.1-schnell](https://huggingface.co/spaces/black-forest-labs/FLUX.1-schnell), and [TRELLIS](https://huggingface.co/spaces/JeffreyXiang/TRELLIS) via [Gradio Client API](https://www.gradio.app/docs/js-client). [Demo](https://rectalogic.com/flux3d)

2024/12 [skypinner](https://github.com/rectalogic/skypinner)
: Unfinished [Next.JS](https://nextjs.org) attempt to implement [Pinboard](https://pinboard.in/) style social bookmarking on top of [BlueSky](https://bsky.app/) [ATProtocol](https://docs.bsky.app/)

2024/10-2024/12 [chainchat](https://github.com/rectalogic/chainchat)
: CLI to chat with [LangChain](https://www.langchain.com) LLM models

2023/10-2024/10 [mediafx-qt](https://github.com/rectalogic/mediafx-qt)
: Nonlinear video editing framework with support for transitions/effects implemented in [Qt QML](https://doc.qt.io/qt-6/qtqml-index.html).

2024/09-2024/10 [llm-transformers](https://github.com/rectalogic/llm-transformers)
: [llm](https://llm.datasette.io/) plugin for [Hugging Face Transformers](https://huggingface.co/docs/transformers/index) [pipeline](https://huggingface.co/docs/transformers/pipeline_tutorial) tasks.

2024/05-2024/09 [mediafx-web](https://github.com/rectalogic/mediafx-web)
: Unfinished [web components](https://open-wc.org) implementing video sequencing with transitions and effects.

2024/09 [kbai](https://github.com/rectalogic/kbai)
: Python tool to generate a video with "Ken Burns" style pan & zoom effects, with transitions between each image. Uses [Grounding DINO](https://huggingface.co/IDEA-Research/grounding-dino-tiny) LLM to identify features in the images to guide the pan/zoom effects.

2024/07 [mediafx-blender](https://github.com/rectalogic/mediafx-blender)
: Unfinished higher level Python wrappers around [Blender Video Sequence Editor APIs](https://www.blender.org/features/video-editing/).
